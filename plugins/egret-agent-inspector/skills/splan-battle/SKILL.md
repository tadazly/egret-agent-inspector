# Splan 战斗

**进 PVE（玩家路径）**：主城「星际探索」（`pve_rect`）→ `btn_go` 进星系（`galaxy_N` 换星系）→ 点正中间那颗星球 `planetImg`（点两边的只会把它转到中间）→ 关卡行（「1 <关卡名>」，没出来就滚一下 `LocaterScroller`）→ `fightBtn`。开场加载和 VS 动画不用点。`sweepBtn*` 是扫荡，会消耗体力。

**回合**

- 左边是我方（「LV:100 <精灵名>」），右边是对手。每回合只能做一件事：出招、换精灵或用道具。
- 倒计时约 11 秒；超时游戏自动出第一个还有次数的技能（我方精灵倒下时自动换上第一只活着的）。
- `egret_act` 在轮到你时才返回（写「轮到你了」），直接出下一招，不要再 observe、wait 或截图；战斗里别传 `turnMs: 0`。同一招连出用 `repeat`。
- 技能行「<技能名> 次数:50/50 威力:200」。次数为 0 或带「被动」的技能点了没用，也不会变灰，自己看次数。

**换精灵**

- 主动换一次发完：`{"steps":[{"id":"petBtn"},{"qaName":"PetListBarItem__headIcon","match":"exact","index":0}]}`，`index` 选第几只（换宠栏不含场上那只）。卡片要按住上滑才生效，工具会自动滑。换精灵占掉本回合。
- 成功标志：左边名字变了、换宠栏收起。倒下（红叉）或上锁的卡换不上。
- 我方精灵倒下：换宠栏自动弹出、技能栏锁住，直接点卡片。

**精灵倒下之后**

- 对手一只精灵被打倒后，有几秒你不能操作，工具会等过去。之后对手的新精灵要到下一回合开头才入场，**界面上还是那只 0 血的精灵，但这一回合你要出招**。act 说「轮到你了」就照常出招，别当成打完了；出现结算页才算结束。
- 左侧「战斗胜利 / 30回合内取得胜利 / 在战斗中自身没有精灵死亡」是关卡三星条件，不是结算；旁边的 `btnClose` 只是把它收起来。

**结算**：写着「轻触屏幕关闭」，用 `{"op":"close"}`；胜利页第一下可能只跳过动画，再关一次。奖励自动到账，没有领取键。

**不要点**

- `autoOn`（自动战斗）、`bagBtn` 展开后的道具和 `hpBtn`、`ppBtn`、`catchBtn`（点了立刻使用，占掉回合）、技能栏上方的「超频」。
- `pauseButton`：弹出的暂停框里 `quitFight` 是退出战斗，直接判负；已经弹出就点 `continueFight`。战斗里不要用 `op=close`。
- 结算里的 `reI`「再战一次」、`refight`、`way_2`「购买高级胶囊」会扣电池或花钱。
- 战斗中弹出剧情对白时倒计时暂停，用 `{"op":"advance"}` 推完再出招。
