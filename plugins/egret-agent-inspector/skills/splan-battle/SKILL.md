# Splan 战斗

**进 PVE（玩家路径）**：主城「星际探索」→「进入星系」（`galaxy_N` 换星系）→ 点星球（表上是星球名，带「未解锁」的进不去）→ 关卡行「1 <关卡名> ★n/3」→「挑战」。星球、关卡都是转盘，点哪一行都行，工具会先转到正中再点。开场加载和 VS 动画不用点。要打简单的：先点 `galaxy_1`（帕诺星系）再「进入星系」，各星球第 1 关对手 10 级左右；默认星系的对手是 100 级、好几只。

**三星**：关卡行的 ★n/3 是已拿到的星；「捕捉关（没有星）」不算星。关卡详情和战斗左侧写着三个条件（如「战斗胜利 / 30回合内取得胜利 / 在战斗中自身没有精灵死亡」），胜利时按这三条判星，要三星就在一场里三条都满足；它不是结算，旁边的「收起三星条件」只是把它收起来。「扫荡」要先三星，会扣电池。

**回合**

- 左边是我方（「LV:100 <精灵名>」），右边是对手。每回合只能做一件事：出招、换精灵或用道具。
- 倒计时约 11 秒；超时游戏自动出第一个还有次数的技能（我方精灵倒下时自动换上第一只活着的）。
- `egret_act` 在轮到你时才返回（写「轮到你了」），直接出下一招，不要再 observe、wait 或截图；战斗里别传 `turnMs: 0`。同一招连出用 `repeat`，打到结算或换宠栏弹出才停。
- 技能行「<技能名> 次数:50/50 威力:200」，带「克制 / 微弱 / 无效」是对当前对手的属性克制。次数为 0 或带「被动（点了没用）」的技能点了不占回合，也不会变灰，自己看次数。

**换精灵**

- 主动换一次发完：`{"steps":[{"id":"petBtn"},{"qaName":"PetListBarItem__headIcon","match":"exact","index":0}]}`，`index` 选第几只（换宠栏不含场上那只）。卡片要按住上滑才生效，工具会自动滑。倒下（红叉）或上锁的卡换不上。换精灵占掉本回合。
- 成功标志：左边名字变了、换宠栏收起。我方精灵倒下时换宠栏自动弹出、技能栏锁住，直接点卡片。

**道具与捕捉**：「道具 / 回血药 / 回PP药 / 捕捉胶囊」只展开道具行，点道具格才用掉并占回合。只有捕捉关和特殊精灵有「捕捉胶囊」；对手血越少越容易抓到。捕捉关把对手打死算失败。

**精灵倒下之后**：对手一只精灵被打倒后，有几秒你不能操作，工具会等过去。之后对手的新精灵要到下一回合开头才入场，**界面上还是那只 0 血的精灵，但这一回合你要出招**。act 说「轮到你了」就照常出招；出现结算页才算结束。

**结算**：胜利、失败、捕捉成功或失败页都用一次 `{"op":"close"}` 关掉（工具会连点跳过动画）。奖励自动到账，没有领取键。

**不要点**

- 「自动战斗（别点）」、技能栏上方的「超频」。
- 「暂停」：弹出的暂停框里 `quitFight` 是退出战斗，直接判负；已经弹出就点 `continueFight`。
- 结算里的「再战一次（扣电池）」、「看攻略」、`way_2`「购买高级胶囊」会扣电池或花钱。
- 战斗中弹出剧情对白时倒计时暂停，用 `{"op":"advance"}` 推完再出招。
